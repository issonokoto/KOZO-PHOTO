# KOZO PHOTO

徳島県クラゲ漁業組合 組合長 山仲幸造さんと、一緒に記念写真を撮るアプリ。

元の dokodemo-nauru の camera/camera.js、camera/text.js、camera/camera.css を土台として独立させています。地図・ゲーム・ランキング・ナウルの素材は使いません。

## 現在の状態

カメラ、写真の読み込み、ポーズ切り替え、移動・拡大縮小・回転・左右反転、文字入れ、名前の表示、保存・共有を実装済み。
添付素材のダウンロード先に接続できなかったため、人物3枚は同梱されていません。「素材を読み込む」で透過PNG3枚を選んでください。ファイル名の「老紳士」「ピース」「親指」などからポーズを振り分けます。読み込んだ素材はそのブラウザのIndexedDBに保存されます。端末内の写真・画像を外部へ送信する処理はありません。共有ボタンを押した場合は端末の共有メニューを開きます。
ブラウザのデータ削除やプライベートモードでは素材の再読み込みが必要になることがあります。

## 人物素材を固定で組み込む

3枚の元PNGを、このフォルダー内に作った incoming フォルダーへ入れ、「npm run assets」を実行します。「老紳士」「ピース」「親指」をファイル名から判別し、assets フォルダーへコピーして poses.js を更新します。数字のファイル名では 001.png＝笑顔、002.png＝ピース、003.png＝サムズアップ として扱います。
そのあと「npm run build」を実行すると、人物素材を埋め込んだ KOZO_PHOTO.html を作れます。固定素材を組み込んだ版では、利用者による素材の読み込みは不要です。
incoming はGitに保存しません。組み込み後の assets/kozo-smile.png、assets/kozo-peace.png、assets/kozo-thumb.png はGitに保存します。

## Git

独立したリポジトリとして main ブランチを作成しています。GitHubに作るリポジトリ名は KOZO-PHOTO、画面上の名前は KOZO PHOTO です。

## 起動

単体版の「KOZO_PHOTO.html」は、ダウンロードしてブラウザで直接開けます。最初に「素材を読み込む」で人物3枚を選んでください。カメラが利用できないブラウザでは「写真を選ぶ」で合成できます。

Node.js があるPCで、このフォルダーに移動して「npm start」を実行し、http://127.0.0.1:4173 を開きます。
スマホからカメラを使う場合は、HTTPSのWebサイトとして配置してください。ファイルを直接開く方法ではJavaScriptモジュールを読み込めません。

## 操作

1. 最初に「素材を読み込む」で人物3枚を選びます。
2. 「カメラを開く」または「写真を選ぶ」で背景を決めます。
3. 笑顔・ピース・サムズアップを選びます。切り替えても位置・大きさを保ちます。
4. 指1本で移動、指2本で拡大・回転。PCはホイールで拡大縮小、Shift＋ホイールで回転。スライダーでも調整できます。
5. シャッター／「完成」を押して保存。対応端末は共有メニューから写真アプリへ保存できます。
