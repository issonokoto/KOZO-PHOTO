# KOHZO PHOTO

徳島県クラゲ漁業組合 組合長 山仲幸造さんと、一緒に記念写真を撮るWebアプリ。

GitHub Pagesの公開先: **https://issonokoto.github.io/KOZO-PHOTO/**

XなどでURLを共有するときの画像・タイトル・説明を、入口のHTMLに登録しています。画像は利用者提供の「KOHZO PHOTO 一般公開」の案内を、切り抜かず1200×600の枠内に収めた `assets/share/kohzo-photo-20261021.png` です。X用のTwitter CardとOpen Graphの両方に同じ公開画像URLを指定しています。サイト側の設定と画像配信を確認しても、X側の取得・キャッシュ・実際の表示までは保証できません。

## GitHubで公開する

このアプリはビルドなしで公開できます。リポジトリ直下の `index.html` が入口です。

1. [Settings → Pages](https://github.com/issonokoto/KOZO-PHOTO/settings/pages) を開きます。
2. **Source: Deploy from a branch** を選びます。
3. **Branch: main**、**Folder: / (root)** を選び、**Save** を押します。
4. GitHub Pagesの公開処理が完了すると、上記URLで使えます。

`.nojekyll` を同梱しています。JavaScript、CSS、画像は同じリポジトリから配信します。

## 使い方

1. 公開URLをスマートフォンで開きます。
2. 「カメラを開く」で撮影するか、「写真を選ぶ」で背景を選びます。
3. 衣装・小道具・ポーズから選び、幸造さんを自分の隣に配置します。検索・ジャンル選択・「おまかせで選ぶ」が使えます。切り替えても配置・大きさ・回転は引き継ぎます。一覧は24種類ずつ表示し、「もっと見る」で続きを選べます。
4. 指1本で移動、指2本で拡大・回転。PCではホイールで拡大縮小、Shift＋ホイールで回転できます。
5. シャッター／「保存」で写真を保存します。対応端末では共有メニューも使えます。

「枠」（PCでは「フレームを選ぶ」）から、徳島のクラゲ、鳴門の渦潮、阿波踊り、すだちとクラゲの4種類を選べます。「枠なし」で解除できます。枠は写真の縦横に合わせて広がり、人物の画像3枚とは別に使えます。写真・カメラ両方で、プレビューと撮影・保存・共有する画像に反映します。[フレームの素材と生成条件](docs/frames.md) を参照してください。

スマートフォンの横画面は、左に「人物・枠・文字・配置」、右にシャッターを置いた撮影優先の配置です。カメラ／写真の切り替えは上部にあります。一覧を開くと専用の欄が現れ、写真にボタンや一覧を重ねません。「閉じる」で写真を広く使えます。一覧を開いたまま人物を動かすこともできます。縦画面では操作ボタンを写真の下に置き、一覧は下側に開きます。

上部の「全画面」を押すと、対応ブラウザーでアドレスバーを隠して使えます。「解除」や端末の戻る操作、PCのEscキーで戻れます。縦横の回転にも追従し、人物・文字・枠の編集や撮影・保存もそのまま使えます。対応していないブラウザーや切り替えが拒否された場合は、ホーム画面への追加方法を案内します。

対応端末では、全画面中だけ `screen.orientation.lock('any')` で縦横の自動回転を許可し、解除時に `unlock()` で端末の標準設定に戻します。通常表示では回転を指定しません。ホーム画面から全画面で起動した場合も同じ扱いです。ブラウザー・OSの制限やユーザー設定によって回転の指定が使えない場合は、端末の回転設定に従い、スマートフォンの画面下に案内を表示します。システム全体の自動回転設定は変更しません。回転指定の対応条件は [Screen Orientation API](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock) を参照してください。

Androidはブラウザーのメニュー、iPhone・iPadはSafariの共有メニューから「ホーム画面に追加」し、追加されたアイコンから起動する方法も使えます。「Webアプリとして開く」が表示される場合はオンにしてください。公開サイトには全画面で起動するためのWeb App Manifestとアイコンを同梱しています。利用できる表示モードは端末とブラウザーにより異なります。単体HTMLファイルはホーム画面への追加に対応しません。

「撮るたびにランダム」をオンにすると、全素材から撮影時に幸造さんが選ばれます。配置・大きさ・回転は引き継ぎ、撮影前のプレビューはそのままです。同じ素材が続かないように選びます。カメラ映像はシャッターを押した瞬間に固定してから素材を読み込み、撮り直しでは再度抽選します。オフにすると選んだ素材で撮れます。

撮影・合成はブラウザー内で行います。撮影した写真を外部へ送信する処理はありません。共有ボタンは端末の共有メニューを開きます。

「文字」の一覧では、各文字の横にある「削除」で個別に消せます。文字を編集する画面の「この文字を削除」からも消せます。削除した分は再び追加でき、ほかの文字や人物は残ります。

完成した画像から保存用URLを作り、「画像を保存」はブラウザーが直接扱うダウンロードリンクとして用意します。スクリプトによる疑似クリックは使いません。「編集に戻る」から背景や素材を変えてもう一度「完成」→「画像を保存」と進めば、続けて別の画像を保存できます。保存画面などへ移動した際も、保存用URLを即座に無効にしないようにしています。ボタンで保存が始まらない場合は、完成画像を長押し（PCは右クリック）して画像として保存できます。

## 開発

Node.jsで `npm run check` を実行すると、JavaScriptの構文と画面要素の参照を確認できます。

別名のPNGで元の3ポーズを差し替える場合は、3枚を `incoming` フォルダーへ置いて `npm run assets` を実行してください。「老紳士」「ピース」「親指」などのファイル名、または `001.png`、`002.png`、`003.png` から判別します。追加素材とそのジャンル・タグは保持します。さらに増やす場合は透過PNGまたはWebPを `assets` に置き、`poses.js` に `id`、`name`、`category`、`tags`、`src`、一覧用の `thumbnail` を追加します。[素材の条件と読み込み](docs/material-library.md) を参照してください。

`npm run build` は、人物画像を配置したあとに、オフライン利用向けの `KOHZO_PHOTO.html` を生成する追加機能です。GitHub Pagesの公開には不要です。

単体HTMLが大きくなりすぎないよう、一部の画像は `assets/offline/` の透過WebPを埋め込みます。公開サイト用の原本・解像度・透明部分は保ちます。書き出し元の内容が `assets/offline/index.json` の記録と一致するときだけ軽量画像を使い、差し替え後に古い画像を埋め込まないようにしています。

元の [dokodemo-nauru](https://github.com/issonokoto/dokodemo-nauru) のカメラ処理を基に独立させました。カメラ、写真読み込み、人物の配置、文字入れ、保存・共有に対応しています。

JavaScriptの構文と画面要素の参照を確認し、PC・スマートフォン幅のブラウザーで素材検索、選択、合成、PNG保存を検証しています。実機のカメラ・iPhoneの共有動作は未確認です。
