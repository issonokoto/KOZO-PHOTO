# アンプ付きエレキベース

元の412種類とエレキベース画像を保ち、「エレキベース（アンプ付き）」を別素材として追加しました。全413種類・19ジャンル、音楽・ステージは37種類です。

素材IDは music-electric-bass-amp。4弦のサンバーストのベース、顔・普段着・ポーズを保ち、コントロールプレート下端の出力ジャックにプラグを挿し、小型ベースアンプ前面のINPUTまで一本のシールドで接続しています。ケーブルの両端は接続済みで、未接続のプラグを残しません。アンプは電池式の練習用モデルを想定しています。

検索「ベースアンプ」で追加1種類、「アンプ付き」で既存のギター2種類と合わせ3種類を選べます。「音楽追加24」など以前の追加数は変えません。

内蔵画像生成ツールで、公開中の assets/library/music-electric-bass.webp を編集元として作成しました。[全プロンプト](bass-amp-prompts.json)を記録しています。PNG原本はローカル作業フォルダー output/bass-amp/originals/music-electric-bass-amp.png、公開用は assets/library/music-electric-bass-amp.webp、一覧用は assets/thumbnails/music-electric-bass-amp.webp、単体HTML用は assets/offline/music-electric-bass-amp.webp です。
