# 素材のジャンルとサブジャンル

全806種類を12ジャンル・87サブジャンルに整理しています。素材は1枚のまま、複数のサブジャンルを紐付けられます。分類ごとの件数には重なりがあり、合計しても素材の総数にはなりません。1つの一覧に同じ素材が重複表示されることはありません。

## 選び方

- 「ジャンル」で大きく絞り、「サブジャンル」で目的のテーマを選びます。
- ジャンルが「すべて」のときも、サブジャンルを直接選べます。対応するジャンルに自動で切り替わります。
- キーワードは両方の分類に重ねて指定できます。おまかせも現在の絞り込みから選びます。
- ジャンルを変更すると、そのジャンルに属さないサブジャンルは解除されます。結果が0件なら「絞り込みを戻す」で全件に戻れます。

たとえば、袴の卒業素材は「イベント・お祝い → 卒業祝い」と「衣装・コスプレ → 和装・浴衣」、赤鬼の妖怪素材は「イベント・お祝い → 節分」と「不思議・ファンタジー → 妖怪・おばけ」から選べます。以前の分類名もキーワードとして使えます。

## 素材を追加・整理するとき

分類の定義は `pose-taxonomy.js` の `POSE_GENRES`、画像への紐付けは `poses.js` の `subgenres` 配列です。例: `["event:graduation", "outfit:japanese"]`。ジャンルはサブジャンルの所属から導き、画像側に二重管理しません。各画像には有効なサブジャンルを1つ以上付けます。空の分類、未定義のID、同じIDの重複は `npm run check` で検出します。

名前・既存タグ・生成条件に記録された衣装や小道具を基に、主題や衣装を付けています。「スケートボード」を冬のスケート、「蝶ネクタイ」を虫、「桜餅」を花として扱わないなど、単語の部分一致をそのまま分類に使いません。

従来の `category` と `tags` はキーワード検索・フレームのテーマ選択の互換性のため保持します。新しい人物選択のジャンル絞り込みには `subgenres` を使います。画像のID・名前・画像パス・従来の分類・タグは今回変更していません。

公開版と単体版の両方が同じ分類定義を使います。単体版を更新するときは `npm run build` を実行します。
