## 使い方

スマートフォンでは画面下の「枠」、PCでは「フレームを選ぶ」を開きます。絞り込みには「すべての枠」「今の季節」「季節・行事」「カテゴリー向け」「徳島・クラゲ」と、素材のジャンルごとの項目があります。項目名の括弧内は該当する枠の数です。

絞り込みを変えても適用中の枠は残ります。どの絞り込みでも先頭の「枠なし」で解除できます。初期状態は枠なしです。写真・カメラどちらでも使え、撮影・保存・共有する写真に反映します。フレームは画像3枚の枠を使いません。枠の上から人物を動かせます。

元画像の四隅の比率を保ち、辺の部分を伸ばして写真の縦横に合わせます。中央の領域は描画しません。プレビューと保存で同じ描画処理を使います。読み込み中は撮影を待ち、失敗した場合は直前の枠を保持します。実寸の枠は選んだときに読み込み、一覧は縮小画像を遅延読み込みします。

## ファイルと生成条件

`frames.js` が素材一覧・分類・対象月と共通描画処理です。公開用の透過WebPは `assets/frames/`、一覧用の縮小WebPは `assets/frames/thumbnails/` にあります。

既存4種類は2026年10月14日に生成し、可逆WebPとして保存しています。PNG原本はローカル作業フォルダーの `output/imagegen/frames/` にあります。[元の生成条件](frame-generation-prompts.json)に、プロンプトと参照画像の役割を記録しています。添付画像はクラゲの形と線の参照として使い、画像下の文字は枠に入れていません。

追加28種類は新規生成した透明背景の画像です。公開用は900×1200、一覧用は150×200の透過WebPで、色の圧縮品質はそれぞれ90・82、アルファ品質は100です。PNG原本と生成記録はローカル作業フォルダーの `output/imagegen/frames-20261027/` に保管しています。[追加28種類の最終生成プロンプト](frame-expansion-prompts.json)も公開しています。中央の透明性と装飾の占有率を確認し、写真の中央を描画しない共通処理で合成します。

オフライン版は `npm run build` で人物素材とフレームを埋め込んで生成します。追加枠の単体HTML用画像は360×480・品質72の透過WebPとして `assets/offline/frames/` に保存し、`assets/offline/index.json` の元画像ハッシュが一致した場合だけ使用します。オンライン版は通常の900×1200画像を使います。
