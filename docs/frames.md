# 徳島とクラゲのフレーム

2026年10月14日、内蔵画像生成ツールで4種類の透過フレームを作成しました。

| フレーム | モチーフ |
| --- | --- |
| 徳島のクラゲ | 添付された青い手描きクラゲ、笑顔、泡 |
| 鳴門の渦潮 | 青い渦潮、波、泡、クラゲ |
| 阿波踊り | 編み笠、うちわ、提灯、踊り手 |
| すだちとクラゲ | すだちの実と断面、葉、小さなクラゲ |

## 使い方

スマートフォンでは画面下の「枠」、PCでは「フレームを選ぶ」を押します。「枠なし」で解除できます。初期状態は枠なしです。写真・カメラどちらでも使え、撮影・保存・共有する写真に反映します。フレームは画像3枚の枠を使いません。枠の上から人物を動かせます。

元画像の四隅の比率を保ち、辺の部分を伸ばして写真の縦横に合わせます。中央の領域は描画しません。プレビューと保存で同じ描画処理を使います。読み込み中は撮影を待ち、失敗した場合は直前の枠を保持します。

## ファイル

`frames.js` が素材一覧と描画処理です。公開用の透過WebPは `assets/frames/`、一覧用の縮小WebPは `assets/frames/thumbnails/` にあります。WebPへの変換は可逆圧縮で透過を維持しています。透過PNG原本はローカル作業フォルダーの `output/imagegen/frames/` に保管しています。

1点ずつの最終生成プロンプトと参照画像の役割は [frame-generation-prompts.json](frame-generation-prompts.json) に記録しています。添付画像はクラゲの形と線の参照として使用し、画像下の文字は枠に入れていません。

オフライン版は `npm run build` で人物素材とフレームを埋め込んで生成します。
