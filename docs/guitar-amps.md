# アンプ付きエレキギター2種類

利用者の希望に合わせ、元の410種類をすべて保ち、アンプ付きの2種類を別素材として追加しました。全412種類・19ジャンル、「音楽・ステージ」は36種類です。元のロックギター幸造・ギターソロの決めポーズは画像・名前・IDを維持しています。

| 追加素材 | 素材ID |
| --- | --- |
| ロックギター幸造（アンプ付き） | plus100-rock-guitar-amp |
| ギターソロの決めポーズ（アンプ付き） | music-guitar-solo-amp |

ギター本体前面の楕円形出力ジャックにプラグを挿し、黒いシールド一本で足元の小型アンプ前面のINPUTまでつないでいます。両端の接続を見せ、未接続のプラグは残しません。アンプは電池式の小型モデルを想定し、電源ランプを点灯させています。

検索「アンプ追加2」でギターの追加2種類を表示できます。続くベース版の追加後は、「アンプ付き」でベースも含め3種類を表示します。「追加100」「音楽追加24」には元の素材を残し、過去の追加数を変えません。

内蔵画像生成ツールで、公開中の各ギター画像に対して段階的に編集しました。[ギター側の接続プロンプト](guitar-cables-prompts.json)、[アンプ追加・両端接続のプロンプト](guitar-amps-prompts.json)を保存しています。編集後のPNG原本はローカル作業フォルダー output/guitar-cable-fix/originals/*-cable-amp.png、公開用は assets/library/*-guitar*-amp.webp、一覧用は assets/thumbnails/、単体HTML用は assets/offline/ に保存しています。別名の画像ファイルにして、元画像のキャッシュを保ちます。
