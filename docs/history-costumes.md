# 歴史の衣装の幸造さん24種類

新ジャンル「歴史の衣装」に24種類を追加しました。日本の古代・中世8種類、日本の近世・近代8種類、世界の歴史衣装8種類です。縄文・弥生・古墳・飛鳥・平安・鎌倉・室町・戦国・江戸・明治・大正・昭和初期を中心に、古代エジプト・ギリシャ・ローマ・唐代中国・中世ヨーロッパなどをそろえています。「歴史追加24」で今回の24種類をまとめて検索できます。

各時代の衣装を参考にした写真合成用の創作素材です。厳密な復元品や特定の歴史人物の再現ではありません。 幸造さんの顔・笑顔・年齢を保って衣装を変えています。以前の624種類の登録内容・公開画像を保ち、全648種類・24ジャンルです。

## 生成と保存先

内蔵画像生成ツールで assets/003.png を人物参照として1点ずつ作成しました。[全プロンプト](history-prompts.json)を記録しています。背景透過PNG原本はローカル作業フォルダー output/history24/originals/ に保存しています。公開用は assets/library/history24-*.webp（原本と同寸法）、一覧用は assets/thumbnails/history24-*.webp（160×240px以内）、単体HTML用は assets/offline/history24-*.webp（長辺1280px以内）です。単体HTML版は容量を抑えるため、一部の既存画像も専用の縮小コピーを利用しています。公開用の既存画像は変更していません。
