# カバラヒを着用した幸造さん・12パターン

ジョージアのチョハとカバラヒを組み合わせた背景透過素材を12種類追加しました。首巻き・肩掛け・フード・頭巻きの4系統に各3種類あり、既存のジョージア衣装2種類と合わせ14種類です。全体は806種類・12ジャンル・87サブジャンルです。

## 着用例を調べた内容

[ジョージア国立図書館の民族資料辞典](https://www.nplg.gov.ge/wikidict/index.php/%E1%83%A7%E1%83%90%E1%83%91%E1%83%90%E1%83%9A%E1%83%90%E1%83%AE%E1%83%98)で、カバラヒの素材、刺繍、房飾り、単独または別の帽子と組み合わせる使用、複数の巻き方があることを確認しました。辞典に地域別の着方への言及はありますが、今回の各デザインを特定地域の正式な型とは呼びません。

首巻きは利用者提供の写真を参照しました。灰色・紺・葡萄色・深緑のフードと肩周りの着用例は、ジョージアの製作者MarisyArtの商品写真を画像検索で確認しました。頭に布を巻いたチョハ着用者の写真も画像検索で確認しています。画像検索の内容と、取得できなかった商品ページは[生成条件・調査メモ](kabalakhi12-prompts.json)に区別して記録しました。

色、衣装、ポーズの組み合わせは写真合成用の創作です。12通りすべてが歴史上の正装として確認できたもの、という意味ではありません。

## 探し方と複数の分類

「衣装・コスプレ → カバラヒ」で12種類を選べます。同じ12種類を「世界の衣装」からも選べるよう、画像ごとに両方のサブジャンルを紐付けました。画像ファイルを重複させているわけではありません。

検索「カバラヒ」「カバラヒ追加12」で12種類、「ジョージア」で以前の2種類を含む14種類。「首巻き」「肩掛け」「フード」「頭巻き」を併せて検索すると、各3種類に絞れます。

内蔵image_genで1点ずつ生成し、PNG原本をローカル作業フォルダーに保管しています。公開用WebP・一覧用・単体版用にも、背景の透明部分を保って書き出しました。プロンプトは [kabalakhi12-prompts.json](kabalakhi12-prompts.json) です。
