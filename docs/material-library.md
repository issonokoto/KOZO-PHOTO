# 幸造さんと一緒に撮るための素材

利用者のカメラ映像や手持ちの写真に幸造さんを置き、一緒に記念写真を撮るための素材です。衣装や小道具は非現実的でも、表現は実写風とします。風景込みの完成写真や、利用者を置く余地のない場面画像にはしません。

元の幸造さんの顔、年齢、表情、体格を参照します。顔を隠す衣装では、ヘルメットやお面を持たせるなどして顔が見える形にします。背景を透明にし、頭・手・足・小道具をできる限り収めます。

## 胸元の表記

元のポロシャツが見える場合、紺色の刺繍は上段「徳島県」、下段「クラゲ漁業組合」の2行にします。下段は「ク・ラ・ゲ・漁・業・組・合」の7文字です。「クラブ」にしないこと。衣装でポロシャツが覆われる場合は、架空の文字や組合名を追加しません。

「クラゲTシャツ」12ポーズは、利用者提供の図案に合わせ、白いTシャツの胸に青いクラゲと黒い「徳島のクラゲ」をプリントします。ポロシャツの刺繍は付けません。[ポーズ一覧と生成条件](tshirt-poses.md) を参照してください。

「徳島！」の24種類は、阿波踊り・すだち・鳴門・藍染めなどの衣装に着替えた全身透過素材です。元のポロシャツを衣装で覆うか着替えており、架空の組合名や文字を追加しません。[衣装一覧と生成条件](tokushima-outfits.md) を参照してください。

「動物の着ぐるみ」の24種類は、幸造さんの顔が見えるフード付きの実写風ぬいぐるみ衣装です。元の帽子・ポロシャツは衣装に着替え、胸元に文字を追加しません。耳・しっぽ・両手・両足まで収めた背景透過素材です。[動物一覧と生成条件](animal-costumes.md) を参照してください。

「全国ご当地」は徳島を除く46都道府県を各1種類追加した創作衣装です。既存の168素材を保ち、色や県名だけを変える作り方を避けて、県ごとに主役のモチーフ・輪郭・素材を分けています。徳島は既存ジャンルで選べます。[県別一覧・差別化方針・参考資料](prefecture-costumes.md) を参照してください。

「追加100パターン」は、音楽・職人・自然・旅・おもちゃを新ジャンルに加え、食べ物・スポーツ・仕事・海・伝説も広げた実写風全身透過素材です。検索欄の「追加100」で今回の100種類に絞れます。[全100種類と生成条件](plus100.md)を参照してください。

「定番」は、元の12ポーズに普段着の自然な仕草24ポーズ、かわいい仕草12ポーズを加えた48種類です。帽子・ポロシャツ・ズボンをそろえ、道具や衣装を増やさず、立ち方・手の仕草・体の向きで変化を付けています。普段着の追加分は「ノーマル」「普段着」、自然な仕草24種類は「定番追加24」、かわいい仕草12種類は「かわいい」「可愛い」「キュート」で検索できます。[一覧と生成条件](normal-poses.md)を参照してください。

かわいい仕草は、顔・年齢・普段着を保ち、手と表情で変化を付けた12ポーズです。動物の小道具や衣装を足さず、人の手でねこの手・うさぎの耳などを表現します。[一覧と生成条件](cute-poses.md)を参照してください。

## 素材と読み込み

- poses.js が公開中の素材一覧です。id、name、category、tags、src、thumbnail を持ちます。
- 元の12ポーズは assets/、新しい衣装・小道具素材は assets/library/、一覧用画像は assets/thumbnails/ にあります。
- 新規素材は内蔵画像生成ツールで1点ずつ生成します。透過PNG原本はローカル作業フォルダーの kozo-library-originals/ に保管し、公開用には同じ構図と透明部分を保ったWebPを書き出します。
- 一覧は24種類ずつ表示します。検索は素材名・ジャンル・タグに対応し、カタカナとひらがなを同じように扱います。「おまかせ」は現在の検索・ジャンル内から選びます。
- 一覧用画像は遅延読み込みし、合成用の大きな人物画像は選んだときに読み込みます。
- 素材を切り替えても、同じ幸造さんの配置・大きさ・回転を引き継ぎます。カメラ・写真選択・撮影・保存が中心の使い方です。

各素材の生成条件は material-library-prompts.json の共通条件に、各項目の spec を連結したものです。再生成時も、顔の一貫性、背景透過、胸元の文字、欠けた手足・小道具を確認してください。
