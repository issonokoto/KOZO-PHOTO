# 音楽・バンド関連24種類

幸造さんの顔・年齢・体格と、いつもの帽子・ポロシャツ姿を保ち、楽器や音楽の役割を増やした全身透過素材です。既存386種類を保ち、合計410種類・19ジャンルです。「音楽・ステージ」は既存10種類と合わせ34種類になります。「定番」は60種類のままです。

検索「音楽追加24」「バンド」で追加24種類に絞れます。ボーカル、ギター、ベース、キーボード、ドラム、管弦楽器、打楽器、録音・音響・準備スタッフを含みます。実在アーティストの個人名・歌詞・楽器メーカーのロゴは使いません。

内蔵画像生成ツールで1点ずつ生成し、assets/003.png を顔・服装・体格の参照にしています。[全プロンプト](music-poses-prompts.json)に条件を保存しています。人物だけでなく楽器・スタンド・機材も同じ透過素材に含めています。楽器を持つ手、管楽器と口の位置、全身と機材の収まり、アルファ透過を確認しています。

透明PNG原本はローカル作業フォルダー output/music24/originals/、公開用は assets/library/music-*.webp、一覧用は assets/thumbnails/music-*.webp、単体HTML用は assets/offline/music-*.webp に保存しています。

ドラムセットはシンバルとスタンドの全体が収まるよう構図を修正し、コンガには足元までの支持スタンドを追加しました。[修正プロンプト](music-poses-revisions.json)も記録しています。

PC幅1366px・スマートフォン幅390pxで、追加24種類すべての選択・読み込み、検索「音楽追加24」「バンド」、合成画像のPNG保存（1200×1600px）を確認しました。警告・エラーは記録されていません。既存386種類の登録内容は維持しています。単体HTMLは配布先の容量制限内に収めるため、一部素材に同寸法・アルファ透過付きの圧縮版を使います。公開サイト用の以前の素材は変更していません。
