# 幸造さん追加100パターン

2026年10月21日追加。既存214種類に100種類を加え、合計314種類・18ジャンルになりました。

元の幸造さんの顔・年齢・体格を参照した、1種類につき1点の実写風全身透過素材です。既存の徳島・クラゲ・衣装シリーズに合わせ、衣装だけでなく持ち物・輪郭・素材感も変えています。色だけを変えた水増しはしていません。

新ジャンルは「音楽・ステージ」「職人・ものづくり」「自然・四季」「レトロ・旅」「おもちゃ・遊び」の5つで各10種類。既存の「食べ物」「スポーツ」「お仕事」「クラゲ・海」「王様・伝説」にも各10種類を追加します。

元のポロシャツは新しい衣装で覆うか着替え、胸に架空の文字を加えません。顔・両手・両足・小道具と背景透過を確認し、生成PNGの透明部分を維持したWebPとサムネイルを書き出します。

生成条件は [plus100-prompts.json](plus100-prompts.json) の basePrompt と各 spec を連結したものです。内蔵 image_gen を使用し、共通の人物参照は assets/001.png。PNG原本と確認用一覧はローカル作業フォルダー output/plus100/、公開素材は assets/library/plus100-*.webp、一覧用画像は assets/thumbnails/plus100-*.webp にあります。

検索欄の「追加100」で今回の100種類だけを表示できます。各ジャンルや名前・小道具のキーワードでも選べます。既存の素材選択・配置・回転・ランダム撮影・保存を引き継ぎます。
