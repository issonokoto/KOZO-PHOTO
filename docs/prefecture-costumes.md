# 全国ご当地の幸造さん — 徳島以外の46都道府県

徳島県を除く46都道府県を各1種類追加した、背景透過・全身・実写風の創作衣装です。徳島県は既存の「徳島！」24種類を利用します。新規46種類を加え、人物素材は214種類です。

「全国ご当地」でまとめて選択でき、都道府県名・読み仮名・モチーフ名でも検索できます。一覧は24種類ずつ表示し、「もっと見る」で46種類になります。

## 重なりを避ける制作方針

既存168素材の主役モチーフを確認し、ラーメン、寿司、たこ焼き、忍者、武将、動物のぬいぐるみ、阿波踊り、藍染めの着物などを新規県別テーマには使っていません。県名や色だけを変える方法ではなく、主役のモチーフ、輪郭、素材の組み合わせを県ごとに割り当てています。

同じ素材系統がある場合も、形状と加工方法を変えています。例えば、岩手は注ぎ口と持ち手のある黒い鉄瓶、佐賀は白磁に青い染付の壺、鹿児島は透明な紅切子の杯です。建物は、埼玉の箱形の蔵、岐阜の三角の茅葺き屋根、東京の細長い鉄骨、広島の横長の鳥居に分けています。

生成後の比較で、茨城の水戸納豆と千葉の落花生が縦長・薄茶色の形で近く見えたため、千葉は横に白い翼が張る「成田の旅客機」へ変更しました。群馬は既存の丸い果物衣装と区別しやすいよう、だるまの顔の絵柄を加えました。青森・福島は頭上の飾りまで収まるように構図の余白を調整しました。
