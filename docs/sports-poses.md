# 競技別スポーツシリーズ48種類

スポーツシリーズを48種類追加しました。球技12種類、陸上8種類、武道・格闘技6種類、水上競技6種類、自転車・体操など10種類、冬季競技6種類です。競技ごとにユニフォーム・靴・防具・道具を変え、全身と道具を背景透過で収めています。「スポーツ追加48」で全48種類、各競技名や「球技」「陸上」「水上競技」「冬季競技」でも絞り込めます。 スポーツジャンルは全70種類、アプリ全体は467種類・19ジャンルです。以前の419種類はすべて保ち、画像も置き換えていません。

夏季・冬季オリンピック種目や一般的なスポーツを幅広く取り上げた創作の記念写真素材です。全48種類を公式オリンピック種目とする一覧ではありません。剣道、男性のリボン演技、小型練習用トランポリンなども含め、親しみやすいポーズにしています。競技選定は [AOCの競技案内](https://www.olympics.com.au/sports/)と[LA28の競技一覧](https://la28.org/en/games-plan/olympics.html?os=win)を参考にしています。

内蔵画像生成ツールで assets/003.png を人物の参照画像として1点ずつ作成しました。幸造さんの顔・年齢・体格を保ち、競技ごとの衣装に着替えています。大会ロゴ、スポンサー名、選手の個人名は付けていません。公開用の透過WebPは原本と同じ寸法、単体HTML用は長辺1280px以内の透過WebP、一覧用は160×240px以内です。

単体HTMLに全467種類を収めるため、既存素材にも87点の軽量な単体HTML用画像を追加・更新しました。うち8点は縦横比と透過を保ち、長辺1280px以内に縮小しています。Webサイトが使う既存の公開用画像と一覧用画像には変更を加えていません。

[全プロンプト](sports-prompts.json)を記録しています。透過PNG原本はローカル作業フォルダー output/sports48/originals/、公開用は assets/library/sports48-*.webp、一覧用は assets/thumbnails/sports48-*.webp、単体HTML用は assets/offline/sports48-*.webp です。
