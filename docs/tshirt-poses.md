# 「徳島のクラゲ」Tシャツ 12ポーズ

利用者提供の青いクラゲと「徳島のクラゲ」の図案を、白いTシャツの胸にプリントした幸造さんです。人物一覧のジャンル「クラゲTシャツ」、またはキーワード「Tシャツ」で選べます。

| 素材ID | ポーズ |
| --- | --- |
| tshirt-peace | ピース |
| tshirt-double-peace | ダブルピース |
| tshirt-thumbs-up | サムズアップ |
| tshirt-wave | 手を振る |
| tshirt-welcome | 両手を広げる |
| tshirt-point | 横を指さす |
| tshirt-cheer | ガッツポーズ |
| tshirt-heart | ハート |
| tshirt-bow | おじぎ |
| tshirt-salute | 敬礼 |
| tshirt-laugh | 大笑い |
| tshirt-hands-on-hips | 腰に手 |

内蔵画像生成ツールで1ポーズずつ作成しました。共通プロンプトと各ポーズの指定は [tshirt-poses-prompts.json](tshirt-poses-prompts.json) に記録しています。幸造さんの顔立ち、年齢、紺色の帽子、ベージュのズボン、黒い靴と腕時計をそろえ、表情とポーズを変えています。

原本は1024×1536pxの透過PNGとしてローカル保管しています。公開用は同じ寸法・構図・透明部分を保ったWebPで、`assets/library/<素材ID>.webp` にあります。一覧用画像は160×240pxの透過WebPで、`assets/thumbnails/<素材ID>.webp` にあります。

新しい12ポーズは既存の108素材に追加しています。検索、ジャンル選択、おまかせ選択、撮影時のランダム選択、写真との合成・保存に利用できます。
